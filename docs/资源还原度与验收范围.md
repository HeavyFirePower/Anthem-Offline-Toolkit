常规静态几何、纹理像素和本地音频已具备全目录计数，可以直接按 ID 提取。骨骼、动画、UI、材质与特效的高精度结果限于表中的具体对象。若验收目标是完整原作画面的相似度，目前只有浮雕等局部参照；用整库解包率、着色器候选率或局部像素误差推算全游戏的单一百分比，缺少相应的成对画面与采样分母。

静态明细可在工作区 `output/static-advanced` 查到。`ue-lod0.jsonl` 每份资产一行，`passes.jsonl` 逐 LOD 列出源 section，`physics-coverage.jsonl` 同时保留部分解码和失败原因，`samples` 包含原型、碎片、局部碰撞三角形与回读结果。其他资源的逐项缺口见[操作教程的支持范围表](操作教程.md#资源类型的实际支持范围)。
