# 用历史录像校准 Fort Tarsis 大厅地板材质

录像中最适合验证的是地上的双人物金色浮雕。它同时出现在大厅远景（115613）和俯视近景（115654），有足够多的刻线可以确认图案、方向和透视。校准期间固定原始纹理、法线解码、金属和光滑度通道以及表面颜色。录像像素只参与定位、估计照明与计算误差。原始网格上的三个 UE 表面可以换灯使用。

## 在已全量解包的安装中重跑

在放有 `Run-Anthem.ps1` 的目录打开 PowerShell。这个命令使用此次录制的四张原尺寸 PNG，按文件名末六位识别。默认定位已有的 `catalog.sqlite` 和 `raw`。可传 `-Output` 指定其他解包目录、`-Destination` 指定结果目录，或用 `-EngineRoot` 指定 5.8.4 的安装目录。Windows 需要 D3D11 和工具包随附的 DirectXTex、原始程序回放器及 UE 验证项目。

```powershell
# 已有能导入 numpy 和 cv2 的 Python 可直接传给 -Python。
py -3.12 -m venv .venv-material
& .\.venv-material\Scripts\python.exe -m pip install "numpy>=1.26,<3" opencv-python-headless==4.11.0.86
$py = (Resolve-Path .\.venv-material\Scripts\python.exe).Path
.\Run-Anthem.ps1 -Mode MaterialRecording -Python $py -ReferenceFrames "$env:USERPROFILE\Downloads" -ImportUE
```

默认结果位于解包目录下的 `converted/recorded-mural`。去掉 `-ImportUE` 可独立运行原程序、提取 FBX 及贴图、生成配准与照明参数。保留该开关会启动两次离屏编辑器，第一次建图并保存资产，第二次重新加载、渲染并回读。UE 内容浏览器路径为 `/Game/AnthemValidation/RecordedMural`。将 `SM_FreelancerFloor06` 拖进自己的关卡即可用自己的灯光检查三个表面。 打开同目录的 `L_FreelancerFloor` 样本关卡，在 Outliner 选择 `Recording_near` 或 `Recording_wide`，通过 Pilot 从该相机查看。场景保存了三槽地板、两盏点光和一盏补光方向光。

## 资产与参数

从 Fort Tarsis 的 Patch bundle `settlement_001/static_content_medium_zs_87` 追踪默认变体和网格内的材质 GUID，得到 `prt_str_freelancer_floor_06_mesh`。浮雕槽 GUID 为 `3d9d75e9-7092-4053-9673-c90e20ac04ef`。该槽三张贴图为 `prt_prp_mural05_diff/norm/amms`，均为 2048×1024、12 级 mip。UE 重开后，36 个解码源 mip 的长度、SHA-1 全部吻合。Diffuse 以 sRGB 采样，其余按线性数据采样。同名的独立道具指向灰色 `mural05b`，其中的 `Diffuse_Tint=2` 属于另一材质。录像对应地板没有此覆盖，使用程序常量表默认的 RGB (1,1,1)。

| LOD0 材质槽 | UE 资产 | 证据范围 |
| --- | --- | --- |
| mural05 | `M_Mural05` | 表面 789474698 的 8,784 个候选（88 个不同 PS，334 个不同 VS）。选择 Patch 状态 1666，PS `cd984782…`，VS `53a46953…`。在 D3D11 同时执行两者，用两个切线基及曝光条件核对四个原始 RGBA 输出 |
| Brass | `M_AgedBrass` | 与浮雕同表面族，实际引用 `gbl_prp_brassaged01` 的 Diffuse、Normal、AMMS。独立外圈几何单独赋材质；平面录像误差不包含立体边框 |
| Floor | `M_FreelancerFloor` | 表面 2038308587 有 408 个候选。按状态 9757 的 PS `a57f7881…` 重建双层材质输入，使用原砖面与粗石的六张贴图、顶点色 R、Mortar、MortarColor、MaskStrength=2.5 和 Smoothness=(0.4,0.8,0,1)。PS 与配对 VS `fbdddffd…` 已执行，砂浆开关及两层纹理在四种输入下完成全部四目标对照 |

浮雕 PS 以 `2 × (Normal.R × Normal.A, Normal.G) − 1` 解码切线法线 XY，正半球重构 Z。RT0.Z 写入 AMMS.A，RT1.RGB 写入 Diffuse 乘 Tint，RT2.Y 写入饱和后的 AMMS.B，RT2.Z 写入 `0.5 × saturate(1.4 × AMMS.R × AMMS.G)`。AMMS.R 还参与 RT3 的间接辐照度。可编辑的 Default Lit 表面用这些数据连接 Base Color、Normal、Metallic、Roughness、Specular 和 AO。UE 的内建照明在这些表面上工作；与原程序逐值核对的是另一个四目标探针。

在空地图中重新加载三个表面及原网格，等待材质编译并读回三次 3D SceneCapture。Brass、Floor、mural05 的像素着色器纹理采样数分别为 3、6、3。160,000 个像素中，147,440 个 Base Color 像素的最大与最小 RGB 分量差大于 0.01；只改变方向光强度，147,436 个像素至少一个线性分量改变超过 0.001。这个俯拍测试验证已保存的三槽材质实际参与网格渲染。

`M_Mural_F9_Buffers` 回读两组 128×128×4 个 RGBA 目标，共 131,072 个 RGBA 像素结果，最大分量绝对误差 2.09×10⁻⁷，在阈值 0.001 下超差为 0。原 VS 实际读取实例记录和矩阵，UE 探针输入相同法线基与辐照度，以验证这两个固定条件下的组合输出。此结果不能外推至整个 VS、全部 8,784 个候选或历史选态。

`M_Floor_F9_Buffers` 与 Default Lit 共用砖地材质函数。砖地候选 PS 写入 RT2.Z 的值为 `0.5 × AMMS.R × AMMS.G`（双层混合后），砂浆边缘缩放所选层法线的 XY，保留 Z。顶点色 R=0、1 用于两端，R=0.42 固定切线基并切换砂浆开关。四种输入共 262,144 个 RGBA 像素结果，最大分量误差 1.82×10⁻⁶，阈值 0.001 下超差为 0。仅切换砂浆就在 RT0 改变 8,165 个像素、RT1 改变 7,952 个像素。两组 PS／VS 合计 393,216 个四分量像素结果。

## 在原镜头内验证表面和光照

在 1024×512 的原浮雕漫反射图案与原尺寸画面之间，用 SIFT 特征及 RANSAC 求平面单应矩阵。另留出空间区块中的匹配点，按 3.5 原图像素阈值统计。近景拟合内点 184 个，留出匹配中 58/96 为内点，其中位误差 1.26 像素、P90 为 1.88。远景对应数字为 94 个、19/69、1.32、2.47。验收范围限于内侧平面；外框厚度、地砖、人物、遮挡以及镜头外区域另行处理。[OpenCV 平面单应与重投影](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)

两个相机的主点取画面中心，假设方形像素和平面比例 2:1，由单应矩阵估计焦距和观察位置。用固定表面重建切线法线与 GGX 高光，先用近景 2,893 个点拟合环境光及一个衰减点光，再用近／远两图的 1,770／1,601 个点联合拟合两盏共享点光和同一环境光。`M_Mural_ControlledLighting` 在 UE GPU 上执行这套可调照明。两张图共用一套灯光、材质和增益。比较采用 320×160 图案空间，原图缩放取区域平均；将 UE 线性输出按 sRGB 编码到 [0,1]，以截图的显示值为目标。未测到录制时的曝光、色调曲线或灯具物理单位。

| 留出区域 | 像素数 | 仅原始 Diffuse 的 RGB MAE | UE 仅环境光 | UE 两灯加环境光 | UE 两灯 RGB RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 115654 浮雕近景 | 11,484 | 0.1764 | 0.2292 | 0.0694 | 0.0947 |
| 115613 大厅远景 | 10,382 | 0.1783 | 0.2918 | 0.0992 | 0.1251 |

此表的留出区块没有参与选灯及拟合。单独用近景调灯后，近景留出区 MAE 为 0.0891；将这组灯原样用于完全未参与光照拟合的远景，41,749 像素 MAE 为 0.1689。两视角共同调灯能改善远景高光，仍有明显的高光位置、宽度与颜色差。这些误差同时含有采样、相机近似、照明和录制链的贡献，不能解读为材质参数误差或视觉还原百分比。

**线性 BC7 和副切线修正后的复测。** 相同两台相机与留出区域，更新后近／远景显示 RGB MAE 为 0.07368／0.09049。四张表面法线分别实测了压缩后角度误差。下段保留更新前网格的灯光与误差基线。[法线方向与 BC7 材质](法线方向与BC7材质.md)

**实际场景灯光。** 从浮雕网格的 UV0 三个角取出世界坐标，将录像相机转换到 UE 地板空间。近／远镜头的估计水平 FOV 分别为 102.91° 和 106.89°。每盏灯单独照射三槽网格，用原图无损缩小后的浮雕内部像素拟合共享的非负 RGB 增益，再打开全部灯，用 Default Lit 渲染真实网格。近景 9,024、远景 1,311 个拟合样本；两幅图使用不同的留出区块像素检验同一组灯。以 800 像素宽画面比较，近景浮雕留出 26,870 个屏幕像素，RGB MAE 由 0.0797 降到 **0.0754**；远景留出 3,885 个，由 0.0952 降到 **0.0939**。这组数字与上表的纹理空间平面实验使用不同像素和渲染路径。场景图来自 UE SceneColor HDR 经 sRGB 编码；相机视口还会受项目后处理影响。近景砖面仍可见较宽的高光，远景浮雕暗部及高光形状仍有差异。

115524 的设备面板、受光砖柱、阴影墙，8 位显示 RGB 的区域中位数分别为 (181,149,116)、(214,151,99)、(19,8,8)。115452 的受光砖面、阴影砖面及右侧掠射光岩壁分别为 (167,113,78)、(28,17,19)、(159,109,79)。这些区域可用来检查场景的亮暗层次及高光方向。设备喷漆、墙面砖和岩壁的唯一材质实例尚未由图案及网格共同定位。

## 其他渲染分支与采集节点

同一浮雕表面的另一个候选状态 457423，PS `315baaf2…`，显式绑定预积分 FG、室外光阴影图、远景阴影缓存、云影、烘焙辐照度、方向和天空可见性（t1 至 t7）；t8 至 t10 对应浮雕自身三张图。可在 `forward-candidate-ps.asm` 复核比较采样及 `gather4_c`。录像提供最终显示结果，尚无法据此选中该前向变体或定位当时的 shadow map、反射探针、光照贴图、后处理、透射、雾和逐帧缓冲。当前同镜头可查看原地板三槽及周围留白，录像数值验收只覆盖浮雕内侧。整个大厅仍待重建。

对采集节点 sapbarnacle 的 Data 和 Patch 两个布局键，再次核查全部九个 F7／F9 材质库的 1,298,888 条状态。共同的 SurfaceShaderId 1688292972 命中 0 条，其小端四字节序列在这九个 RES 中也没有出现。文件级结果记录于 `sapbarnacle-search.json`。两键继续列为缺候选，全局加局部的覆盖仍为 1,718/1,720。
