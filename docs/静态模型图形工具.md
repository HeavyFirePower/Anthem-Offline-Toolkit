# 静态模型图形导出与 UE 5.8.4 导入

## 按游戏路径导出

双击工具目录的 `Export-StaticMeshes.pyw`。本机使用 Windows Python 3.12 和随 Python 安装的 Tkinter。若双击打开了代码编辑器，可在同一目录运行 `python .\Export-StaticMeshes.pyw`。

1. 在「解包目录」选择包含 `catalog.sqlite` 和 `raw` 的完整解包目录。本机是 `Games\Anthem-Extracted\anthem`。打开时会读取静态模型清单。变更输入目录后点击「读取目录」。
2. 按完整路径、路径片段或资源 ID 筛选。可用 Ctrl 或 Shift 多选、「选中匹配项」批选，或「随机选 4 个」抽样。只列出已解包的刚性与复合 MeshSet。
3. 选择「输出父目录」。默认导出常规渲染几何的 LOD0 FBX。「同时导出 USDA」会为相同几何增加一份文本 USD，适合检查 section 和顶点属性。「全部 LOD」为每级写独立文件，导入器会将它们装回同一个 StaticMesh。
4. 点击「导出选中项」，完成后用「打开结果目录」查看。每次建立新的批次目录。输入的原始路径、代表资源 ID、所选记录的 Data／Patch 来源、每级文件名、FBX SHA-256、源面数和 UV 通道数写入批次根目录的 `anthem-meshes.json`。失败项列在 `errors`。

文件直接沿用 MeshSet 的虚拟资源目录，例如 `environments/shaper/structures/meshes/shp_str_brace_01_mesh.fbx`。LOD0 使用原名，后续级别增加 `_LOD1` 等后缀。同一资源路径有多个不同内容或 RES 元数据版本时，每个版本带稳定的 ID 后缀，避免覆盖；清单可查原名。批次中配套的 FBX 和 USDA 可以随清单一起移动。

FBX 使用本机 UE 5.8 安装附带的 Autodesk FBX SDK 2020.2。UE 安装在其他位置时，可设环境变量 `ANTHEM_FBX_SDK_BIN` 指向包含 `libfbxsdk.dll` 的目录。可选的 USD 采用 `.usda`，可直接用文本编辑器查看，也能由 OpenUSD 打开。当前 UE 导入器读取同批 FBX。几何保留源材质槽，材质与纹理的还原走独立工具。

## 导入自己的 UE 工程

1. 双击 `Import-StaticMeshes-UE.pyw`，或运行 `python .\Import-StaticMeshes-UE.pyw`，选择批次内的 `anthem-meshes.json`。窗口默认选中该批所有成功导出的资产，也可筛选后只选需要的条目。
2. 选择目标 `.uproject` 和 UE 5.8.4 安装根目录。目标项目需启用 Python Editor Script Plugin。内容根路径默认为 `/Game/Anthem`。例如上述支架会写入 `/Game/Anthem/environments/shaper/structures/meshes/`。
3. 点击「导入并保存选中项」。工具使用独立无界面编辑器进程。每个模型的 LOD0 先建成 StaticMesh，随后按源级别导入其余 LOD。验收后保存 `.uasset`。结果和 UE 日志在目标工程的 `Saved/AnthemImport/<批次>/`。
4. 在 Content Browser 打开网格，在 Static Mesh Editor 切换 LOD。可在 **Nanite Settings** 检查 Nanite，在各级 **Build Settings** 检查 Recompute Normals 和 Recompute Tangents。

| 设置 | 导入值或验收方式 |
| --- | --- |
| Nanite | 关闭 Build Nanite，读取 StaticMesh 的 Nanite Settings 确认关闭 |
| 法线与切线 | 导入源法线和切线，各级关闭重新计算并回读 |
| 颜色、UV | 使用源顶点色，关闭生成 Lightmap UV，逐 LOD 核对 UV 通道数 |
| 几何和比例 | 同资产的常规 section 合并为一个 StaticMesh，启用场景单位换算，关闭主动删除退化面。构建面数须与源相等，或差值恰等于源零面积面数 |
| 碰撞与材质 | 关闭自动生成碰撞、材质和纹理。原始碰撞 FBX、阴影／深度及拆件请使用原有命令行选项 |
| 已有资产 | 已由本工具导入且源 ID、各级 FBX 哈希均相同，则复核现有资产。其他同名资产在报告中标为冲突，可指定另一内容根路径 |

## 命令行

原有 `Run-Anthem.ps1 -Mode StaticMesh` 的输出和参数继续可用。按游戏虚拟路径保存时，增加 `-OriginalPaths`。可以传 `-AssetId`（GUI 版本记录的完整 ID）、`-Match`、`-Limit` 或 `-All`。指定的 `-Destination` 是本次要新建的目录，省略时会自动建立新批次。下例同时输出 FBX、USDA 和各级 LOD。

```powershell
.\Run-Anthem.ps1 -Mode StaticMesh -OriginalPaths -Match shp_str_brace_01_mesh -Limit 1 -Format both -AllLods
```

## 随机样本验收

从本安装的静态资源名前缀与内容版本清单按固定种子 `20261115` 随机抽 4 份。输出目录 `output/StaticMesh-Preview-01` 内的 `Meshes` 是交换文件，`UE/AnthemPreview.uproject` 是可打开的 UE 工程。几何预览使用中性颜色。喷泉水面和特效拖尾的最终外观还需要原作材质。

| 样本 | LOD 级数 | LOD0 源三角面 | UV 通道 |
| --- | ---: | ---: | ---: |
| 庭院喷泉水面 | 1 | 68 | 1 |
| 外墙支撑 | 4 | 3,566 | 2 |
| Shaper 支架 | 6 | 9,983 | 2 |
| 特效拖尾网格 | 1 | 368 | 1 |

12 份 FBX 的 195 组数组通过 SDK 逐值比对，12 份 USDA 的顶点及三角索引通过 OpenUSD 回读。UE 5.8.4 保存 4 个 StaticMesh，由独立进程重开，全部 12 级 LOD 的面数、UV 通道数通过验收，Nanite、重新计算法线和重新计算切线均为关闭。详细记录在预览目录的 `Reports`。[静态模型完整支持范围](静态模型与场景.md)
