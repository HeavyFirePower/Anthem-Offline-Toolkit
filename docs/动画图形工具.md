# 动画 FBX 导出与 UE 5.8.4 导入

## 先看样本

工作区的 `output/Animation-Preview-02` 包含三套配对。打开 `UE/AnthemAnimationPreview.uproject`，在内容浏览器选择 `Content/Anthem/animations`，按「动画序列」筛选。双击片段后，动画编辑器会载入随片段设置的预览网格。截击号与巨像号使用各自的基础内构网格。批次没有绑定装备外壳、武器或贴图。

| 动作 | 原始片段 | 骨架骨数 | 有动画的骨轨 | 采样姿势 | 时长 |
| --- | --- | ---: | ---: | ---: | ---: |
| 截击号空中翻转 | `EXF_NOV_CBT_Aimed_Rifle_InAir_Jump_FrontTwist_FL` | 202 | 88 | 96 | 3.167 秒 |
| 蛛形生物向左转身 | `ARA_PTM_Moving_Turn_Left_135` | 117 | 75 | 76 | 2.500 秒 |
| 巨像号向前侧步 | `EXH_Walk_StrafeForward_OnSpot_Unarmed_FL` | 183 | 67 | 61 | 2.000 秒 |

三段均为 30 fps，源帧号从 0 开始，时长按末帧号除以帧率计算。截取每 0.1 秒的 UE 压缩姿势即可观察模型形变。样本中的动图使用 LOD0 三角形、源权重与中性着色，视角随各模型居中。

## 导出

1. 在工具目录双击 `Export-Animations.pyw`。选含 `catalog.sqlite`、`raw` 的已解包目录并读取。可按游戏路径、骨架名、动画名或控制器键搜索。
2. 手选片段，或点「随机选 3 套」。随机操作从当前筛选中按不同骨架抽取，选到的每个动作随附一份配对的 LOD0 骨骼模型。多个动作共用模型时，每批只导出一次该模型。
3. 指定输出父目录，点「导出选中项」。每次创建独立批次目录。动画文件按 `<AssetBank 的游戏虚拟路径>/<原始控制器名>.fbx` 存放，模型按各自 MeshSet 的游戏路径存放。同路径同名版本追加来源 ID 的短摘要。
4. `anthem-animations.json` 记录 FBX、模型 ID、源帧率、控制器参数、验收值和失败原因。`anthem-skeletal.json` 记录模型与骨架。`_evidence` 保留源压缩键解码结果、辅助通道、目标骨轨与蒙皮数据。移动或交付时复制整份批次。

导出的动画是一个含完整参考骨架和一个动画片段的二进制 FBX；几何和蒙皮在配对模型 FBX 里。FBX SDK 每次重新打开写出的动画，逐骨逐帧检查局部平移和旋转。需 Python 3.12、Tk 和 FBX SDK 2020.2 运行库。工具默认查找本机 `UE_5.8/Engine/Binaries/ThirdParty/FBX/2020.2/Win64`，也支持环境变量 `ANTHEM_FBX_SDK_BIN`。

## 导入 UE

1. 双击 `Import-Animations-UE.pyw`，选 `anthem-animations.json`、目标 `.uproject` 和 UE 5.8.4 安装目录。默认内容根为 `/Game/Anthem`。UE 包名中的空格、句点和连字符会转换为下划线，原始名称记录在清单。
2. 读取清单、选择片段，点「导入并保存选中项」。导入器先校验源文件 SHA-256，再导入相应的 SkeletalMesh、Skeleton 和动画 FBX。使用导出时间范围、源帧率、局部变换与骨轨。模型使用导入的法线和切线，关闭 Nanite 和重新计算。动画批次关闭纹理和材质导入。
3. 导入器重启一个 UE 进程，重新读取保存的资产，检查骨架、蒙皮、帧数、时长和每个有动画的骨骼。窗口会给出两次报告位置，默认在目标工程的 `Saved/AnthemImport`。包名已被其他资产占用时会报告失败。

FBX 和 UE RAW 的一般门限为 0.01 cm、0.02°。UE 的 Sequencer 动画模型会将旋转转为欧拉角。个别接近俯仰奇点的键，工具同时核对引擎转换值和源四元数，仅接受转换残差 ≤0.02° 且对源误差 ≤0.085° 的情况。蛛形生物 5,700 个骨骼姿势中有 1 个这样的键，源差 0.041738°，引擎转换残差 0.000005°。对 UE 压缩后的计量始终直接使用源四元数。三套共核 18,235 个骨骼姿势，压缩后的最大误差为 0.00951 cm、0.132°。样本另用独立的 PIE 世界从头播放到末帧，逐次读取模型骨骼的位置，详见样本 `Reports`。

## 命令行与覆盖

原有 `Run-Anthem.ps1 -Mode Animation`、`AnimationList` 继续提供源键导出和按指定骨架解码。按原路径批量导出 FBX 可用下列命令，新批次目录必须尚未存在。

```powershell
python tools/animation_library.py --random-sets 3 --seed 20261115 --dest output/MyAnimationSample
python tools/animation_library.py --match SBR_AS_Sleeping --dest output/MySpacebearClips
```

本安装筛出 21,458 条库内候选，含 4,541 个不同动画键，覆盖 HMM、EXH、EXF、ARA、SBR、BDG 六套骨架。同一动作可能随多个游戏库分发。候选筛选要求支持的绝对 ECLP 编码、同库控制器和映射、完整整数帧区间、已配对的骨架与模型，随后对每个实际选择的动作核验通道及 FBX。名称相同的重复骨轨只有在各源采样帧完全一致时才会合并。增量混合、裁切、缺失的跨库引用、运行时 IK、根运动策略与状态机仍需逐项研究。清单里的源控制器 `time_scale` 独立保留，工具以片段采样时间播放。原作实机状态下的变速和最终表演尚待对照。
