## 按原路径导出

1. 双击 `Export-Audio.pyw`。选含 `catalog.sqlite` 和 `raw` 的解包目录，点击「读取目录」。可按原路径、变体后缀、ID 或「语音」「音乐」「音效」筛选。
2. 选择一条或多条变体，或点「随机选 4 条」。随机选择会尽量覆盖不同试听类别和有明确库表循环的声音。类型标签依据路径。每条声音的实际采样参数由源文件确定。
3. 选择输出父目录并点「导出选中项」。工具创建新的批次文件夹。单变体使用 `<原游戏路径>.wav`，多变体使用 `<原游戏路径>__vNNNN.wav`，同名版本发生目标路径冲突时追加库 ID 的前 16 位。
4. `anthem-audio.json` 记录每条 WAV 的相对路径、源库、CAS、原始分段、帧数、循环来源和校验值。复制整个批次即可换位置导入。每条 WAV 包含完整的一遍音频，保留源采样率、声道次序和所有可确认的循环端点。

本安装显示 67,811 条路径／内容版本／变体组合。其中 24,326 条来自 NewWave，包含相同库内容在不同路径下的记录。旧式 SoundWaveAsset 包含 42,754 条英文语音和 731 条音乐。德、西、法、意语音库缺少完整音频块，其变体不进入可选列表。随包附带的目录加速索引按库内容哈希匹配，输出前重新读取源数据。WAV 解码使用随工具提供的 vgmstream。

## 导入 UE 5.8.4

1. 双击 `Import-Audio-UE.pyw`，选择批次的 `anthem-audio.json`、目标 `.uproject`、引擎安装目录。默认内容根为 `/Game/Anthem`。UE 包目录沿用游戏层级，包名中的句点、空格和连字符转为下划线。
2. 读取清单，选中需要的行（可多选），点「导入并保存选中项」。程序在本机启动后台编辑器，载入工具附带的 AnthemAudioEditor 验收插件。使用普通 SoundWave 保存结果。已占用的异源包路径会报告冲突。
3. 导入采用 PCM 压缩设置、Max 采样率质量、音量 1、音高 1。这样可用于对照原始解码数据。工程的平台采样设置和实际播放设备仍可影响打包后的输出。直接播放设为单遍，有依据的循环区间保存在 SoundWave 原生 loop region 中，供播放逻辑使用。
4. 保存后，第二个 UE 进程重新检查完整源 PCM 哈希、声道数、采样率、时长、压缩设置和循环区间。窗口显示报告路径，位于目标工程的 `Saved/AnthemImport`。示例报告已放入样本的 `Reports`。原作的实时混音、空间路由和交互音乐切换未在这些单条 SoundWave 中重建。

## 命令行

原有 `Run-Anthem.ps1 -Mode Audio`、`AudioList`、`AudioTrace` 均可继续使用。批量导出器另提供与 GUI 共用的按原路径导出入口，目标批次目录须为新目录。

```powershell
python tools/audio_library.py --random 4 --seed 20261115 --dest output/MyAudioSample
python tools/audio_library.py --match ui_ig_pickups --dest output/MyPickupSounds
```
