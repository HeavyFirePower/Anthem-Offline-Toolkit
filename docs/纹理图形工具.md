# 纹理 TGA 导出与 UE 5.8.4 图形导入

## 先看三套样本

打开 `output/Texture-Preview-01/Texture-preview.png` 可同时看三套图的 RGB。打开 `UE/AnthemTexturePreview.uproject`，在内容浏览器的 `/Game/Anthem` 下查看 12 个纹理资产。三张表面法线旁各附一个 `M_…_RG`，可在材质编辑器查看法线重建节点。主 TGA 和完整批次清单位于 `Textures`。

| 原作材质使用者 | 该材质实际引用的槽 | 张数 |
| --- | --- | ---: |
| Praetorian 支撑脚 | Diffuse、Normal、Dirt、Stack | 4 |
| Dax 落石道具的技术饰边 | Diffuse、Normal、AMMS | 3 |
| 自由职业者 NPC 上装 | Diffuse、Normal、CharacterClothDetailData、OSM_Mask、Tint_Mask | 5 |

按固定种子 `20261115` 抽取，逐套回查原作 owner EBX 和材质对象。12 张二维图共 136 个源 mip。独立 TGA 读取器对照解包像素，随后在 UE 5.8.4 重开工程读回每级源像素，均逐字节一致。三张法线的实际平台格式均为 BC7。材质槽记录说明贴图被谁引用，完整材质还涉及程序变体、参数和光照。

## 导出

1. 双击 `Export-Textures.pyw`。本机使用 Windows Python 3.12 与 Tkinter。若双击被关联到编辑器，在工具根目录运行 `python .\Export-Textures.pyw`。
2. 选择包含 `catalog.sqlite` 和 `raw` 的解包目录。本机是 `Games\Anthem-Extracted\anthem`。可以按路径或版本 ID 筛选，Ctrl、Shift 多选，也可以「选中匹配项」批选。
3. 「随机选 3 套」从当前筛选中选取三个完整、互不共用贴图的材质套组。随包索引来自原作 Mesh EBX 的材质对象、参数槽、TextureAsset 名称和 RID。当前安装可列出 **24,414 个纹理版本、23,673 个名称**。**2,205 套**满足随机抽样条件，包括至少三个有明确引用的槽、Normal 和 Diffuse 或 BaseColor。目录中的其他纹理也可以手选导出。
4. 指定输出父目录并点「导出选中项」。每批新建一个 `Textures-…` 目录。主文件使用游戏虚拟路径，例如 `environments/settlements/textures/set_techtrim01_norm.tga`。同路径存在不同版本时加稳定 ID 后缀。清单 `anthem-textures.json` 记录源名称、ID、RID、chunk、维度、颜色空间、各级像素校验值、导入策略、选中的整套引用及失败原因。

| 纹理 | 可查看的文件 | 用于还原 UE 纹理的数据 |
| --- | --- | --- |
| 可按 8 位通道表示的普通二维纹理 | 原名 `.tga`，含 mip 0、RGBA、左上原点 | 主 TGA 提供最高级像素。若有后续级别，同名 `.mips.zip` 内含 `mip01.tga` 等原作 mip。GUI 从这些 TGA 重组完整链 |
| 浮点、高精度或深度二维纹理 | 原名 `.tga` 为 8 位预览 | 同名 `.dds` 保存可供 UE 导入的高精度解码数据和原有 mip |
| Cube、2DArray、3D | `.planes` 目录分别包含六面、各数组层或所有 mip 0 的 Z 切片 | 同名 `.dds` 保存完整维度与全部源 mip。Cube 面按 DDS 轴命名，世界方向还取决于原作探针变换 |

直接查看主 TGA 即可。搬移或交给 UE 图形导入时，请一起移动批次清单和配套文件。图形导入器校验批次的原始像素；若只需导入自行修改的单张 TGA，可用 UE 内容浏览器导入并生成新的 mip 链。

## 导入 UE

1. 双击 `Import-Textures-UE.pyw`，选择批次根目录下的 `anthem-textures.json`。读取后默认选中全部成功项，可只选其中几张。
2. 选择目标 `.uproject`、UE 5.8.4 安装根目录和内容根路径，默认 `/Game/Anthem`。引擎安装需包含 Python Editor Script Plugin 和 Editor Scripting Utilities。工具包附有该引擎版本的源像素回读插件。
3. 点击「导入并保存选中项」。工具在项目下沿原虚拟目录生成 Texture2D、TextureCube、Texture2DArray 或 VolumeTexture。UE 包名会把不支持的标点替换为下划线。普通二维纹理从 TGA 合成的 DDS 保存在工程 `SourceArt/AnthemTextures`，供 UE 再导入使用。
4. 导入完成后工具启动第二个 UE 进程，重新打开已保存资产，核对类、尺寸、层数、sRGB、压缩设置、mip 策略、每级字节数和像素哈希。源校验对比的是 UE Texture Source。平台有损块压缩的误差需另行度量。同一批次重跑时会复核已有同源资产，遇到其他来源的同名对象则报告冲突。
5. 两次结果各在工程 `Saved/AnthemImport/<批次>/result.json`。源纹理和保存的 UE 资产可按清单中的虚拟路径相互查找。

| 用途 | 本版导入设置 |
| --- | --- |
| 颜色和遮罩 | sRGB 来自源格式与头标志。常规 BC1／BC3 颜色使用 Default，线性 BC1／BC3 遮罩使用 Masks，保留四分量源和原作 mip。具体 R、G、B、A 含义取决于使用它的材质槽 |
| 双通道表面法线 | 对识别出的二维 BC5 表面法线使用线性 BC7，关闭 sRGB 和 Flip Green Channel。配套材质线性读取 RG，映射到 −1 至 1，通过 `sqrt(saturate(1-dot(xy,xy)))` 重建正 Z。可调 `TangentYSign` 默认 −1，来自此前的地板 FBX 切线基验证；本轮三个原模型的逐面 Y 方向仍待对照 |
| 单通道、浮点与特殊数据 | BC4 选 Alpha 从 R 构建，R8／16 位深度采用 Grayscale。RGBA16F、RGBA32F 分别使用 HDR、HDR High Precision。部分 RGBA8 数据保留未压缩设置。方向场、烘焙光照、复合遮罩需按各自使用方式采样 |

另测了 33³ 浮点 LUT、六面 RGBA16F 探针、六层 G16 深度数组及 RGBA32F 天空渐变。四项在 UE 重开后保留类型、精度及全部源 mip。本安装缺少 1D、1DArray 和 CubeArray 的实物样本。目录普查与本轮 GUI 验收的统计口径见[资源还原度与验收范围](资源还原度与验收范围.md)。

## 命令行

原有 `Run-Anthem.ps1 -Mode Texture` 继续提供 DDS 和通道检查。按原路径输出 GUI 同款 TGA 批次，可用新的 Python 命令。输出目录须是新目录。

```powershell
python .\tools\texture_library.py --random-sets 3 --seed 20261115 --dest .\Texture-Sample
python .\tools\texture_library.py --match set_techtrim01 --dest .\TechTrim
.\Run-Anthem.ps1 -Mode Texture -Match environments/settlements/textures/set_techtrim01_norm
```

需要指定解包目录时传 `--catalog`，需要指定单一版本时传 `--id`。重建套组索引可用 `build_texture_set_index.py` 读取既有 `mesh-material-bindings.jsonl`。每个去重后的槽位组合保留一个可回查的 owner ID 和材质对象 GUID。
