# 骨骼模型图形导出与 UE 5.8.4 导入

骨骼和静态模型共用一个工具包。双击 `Export-SkeletalMeshes.pyw` 导出骨骼模型，双击 `Import-SkeletalMeshes-UE.pyw` 将它们导入 Unreal。两个静态模型入口仍在同一目录。双击关联到编辑器时，可在工具包根目录用 `python .\Export-SkeletalMeshes.pyw` 或 `python .\Import-SkeletalMeshes-UE.pyw` 启动。本机验证环境为 Windows、Python 3.12 和 Tkinter。

## 按游戏原路径导出

1. 选择含 `catalog.sqlite` 和 `raw` 的完整解包目录。本机为 `Games\Anthem-Extracted\anthem`。窗口列出蒙皮 MeshSet，可按路径、名称片段或版本 ID 筛选并多选。
2. 第一次可点「随机选 4 个已配对」。本安装有 1,233 个去除重复打包后的蒙皮 MeshSet 版本，15 个有现成的配对记录，包括 Spacebear、9 个角色或外骨骼基础网格及 5 件截击者装备。导出时会核查 SkinnedMeshAsset 的 RID、骨架类型、骨骼数、section 调色板和顶点权重。模板配对还会核对 owner 和 master 引用。
3. 「待指定」模型需在「未配对模型骨架」选择已知的源骨架，也可输入 SkeletonAsset 的完整 EBX ID 或唯一的 Patch 虚拟路径。下拉菜单在本安装列出 87 个 `animation/*_skeleton` 下的已识别 SkeletonAsset 内容版本。同批待指定模型使用同一个手选骨架，不同骨架可分批导出。手选记录标记为 `explicit_skeleton`。骨数和权重合法仍可能对应不同的骨序，确认原作配对需要模板或装备引用证据。
4. 默认导出 LOD0 FBX。「同时导出 USDA」增加带 UsdSkel 骨架和蒙皮的文本 USD，可在 DCC 中检查骨名、层级、rest pose、bind pose 和逐点权重。源 LOD 每批可选一级，选择 LOD1 等会在文件名加 `_LOD1` 等后缀，导入 UE 时作为该独立网格的基础级。当前实现提供 `.fbx` 和 `.usda` 两种交换文件。
5. 选「输出父目录」，点击「导出选中项」。每批新建目录，例如 `enemies/creatures/ara_arachnid/ara_arachnid_model_mesh.fbx`。同路径的不同内容或元数据版本使用来源 ID 后缀区分。批次根目录的 `anthem-skeletal.json` 记录原名、网格与骨架 ID、配对依据、文件校验值、FBX SDK 回读结果及失败原因。`_evidence` 的压缩文件用于逐点对照。移动批次时请一起移动上述文件和子目录。

FBX 写入器使用 UE 安装附带的 FBX SDK 2020.2。若 UE 安装位置不同，请将环境变量 `ANTHEM_FBX_SDK_BIN` 指到包含 `libfbxsdk.dll` 的目录。USDA 保留源 Y 向上、米制坐标，并把骨架和各个材质 section 写在同一 SkelRoot 下。网格保留源材质槽，游戏材质与纹理通过独立工具还原。

## 导入 UE 工程

1. 打开骨骼导入窗口，选择导出批次的 `anthem-skeletal.json`。读取清单后可筛选、取消选择或只导入一个模型。
2. 选择目标 `.uproject`、UE 5.8.4 安装目录和目标内容根路径。默认在 `/Game/Anthem` 下沿用源虚拟目录。UE 包名中的空格或连字符会转为下划线。目标项目需启用 Python Editor Script Plugin，安装中需提供 Mesh Modeling Toolset 供权重回读。
3. 点击「导入并保存选中项」。独立 UE 进程通过 FBX 建立 SkeletalMesh，并在同目录为每个网格保存一个配套的 `_Skeleton`。不同服装部件各自携带完整绑定骨架，便于独立查看。动画、PhysicsAsset 和原作材质需通过相应的专门流程处理。
4. 打开 Skeletal Mesh Editor，以 Skeleton Tree 查看层级和参考姿势。**Nanite 关闭，Recompute Normals 和 Recompute Tangents 均关闭**。导入使用源法线、切线、顶点色和场景单位转换。工具检查骨名、父子关系、模型空间骨骼位置与基轴，以及每个源控制点的骨骼和权重，通过后保存。
5. 每次结果在目标工程 `Saved/AnthemImport/<批次>/result.json`，引擎日志在同目录。同一批次再次导入会检查已有的同源资产。遇到其他来源的同名资产时报告冲突，可选择另一个内容根目录。

## 命令行

原有 `Run-Anthem.ps1 -Mode SkeletalMesh` 支持单模型、骨架、owner 和 master 的显式配对。以下三条命令分别用于原版 Spacebear 导出、按原路径导出蛛形生物的 FBX 和 USDA，以及按固定种子重现本次抽样。最后一条请指定尚不存在的输出目录。

```powershell
.\Run-Anthem.ps1 -Mode SkeletalMesh
.\Run-Anthem.ps1 -Mode SkeletalMesh -OriginalPaths -Match ara_arachnid_model_mesh -Format both
python .\tools\skeletal_library.py --random 4 --seed 20261115 --usda --dest .\Skeletal-Sample
```

## 四份随机样本

抽样范围为本安装有自动配对记录的 15 个版本，种子为 `20261115`。预览目录 `output/SkeletalMesh-Preview-01` 中的 `Meshes` 为可移动导出批次，`UE/AnthemSkeletalPreview.uproject` 可直接打开，`Reports` 含导入、独立 UE 进程重开和 OpenUSD 回读记录。预览图展示绑定姿势下的中性几何。

| LOD0 样本 | 骨骼 | 源控制点 | 源三角面 |
| --- | ---: | ---: | ---: |
| 哨兵 | 183 | 39,609 | 40,475 |
| 蛛形生物 | 117 | 20,919 | 19,257 |
| 截击者基础头盔 | 202 | 4,979 | 6,726 |
| 截击者 Bomber 躯干 | 202 | 17,024 | 21,619 |

UE 重开后，82,531 个源控制点的同索引权重全部通过，最大单项归一化权重误差为 `2.97e-8`，骨骼位置最大分量误差为 `0.0000542 cm`。UE 的 MeshDescription 包含 87,655 个点，新增点的权重组合均可在源数据中找到。OpenUSD 回读四个层级、9 个 section 的顶点与关节权重，并对每个 section 的一根受权重驱动的关节施加 0.25 米测试平移。绑定姿势和该测试形变的最大分量误差均小于 `2.4e-7 m`。另从导出窗口测过蛛形生物的独立 LOD1 FBX。
